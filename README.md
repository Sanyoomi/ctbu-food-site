# 工商觅食记 🍜

重庆工商大学南岸校区周边美食主题的 Web 课程作业，使用原生 HTML、CSS、JavaScript 实现，无框架、无后端、无数据库。

## 页面与功能

| 页面 | 内容 |
| --- | --- |
| index.html | 选题介绍、11 道美食统计、三个觅食片区入口 |
| foods.html | 校内食堂、回龙湾、五公里·六公里三个分类及图文清单 |
| share.html | 昵称、美食名称、推荐理由、确认勾选组成的投稿表单 |

三个主要交互：分类选项卡切换、投稿表单逐项校验、滚动超过一屏后显示返回顶部按钮。
CSS 包含渐变背景、卡片悬停效果，以及屏幕宽度不超过 680px 时的布局调整。

**投稿功能为前端交互演示：通过校验后显示成功提示并清空表单，不会上传或保存数据。**
图片和价格文字属于课程展示内容。

## 如何运行与验收

本项目统一使用 Python 本地 HTTP 服务器运行和验收，不使用双击 HTML 文件或 file:// 地址验收。

1. 确认已安装 Python 3，并能在终端执行 `python --version`。
2. 打开终端，切换到包含 index.html 的项目根目录。
3. 执行以下命令，保持终端运行：

```sh
python -m http.server 8000
```

4. 在浏览器地址栏输入 http://localhost:8000/ 。
5. 按 F12 打开开发者工具的 Console（控制台），刷新页面，再依次访问首页、觅食清单和投稿页。
6. 验证分类切换、返回顶部、空表单错误提示和正确填写后的成功提示，确认没有红色报错或资源 404。

验收结束后，在服务器终端按 Ctrl+C 停止服务。如果 8000 端口已占用，可换用 8001，并同步修改浏览器访问端口。
